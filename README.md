# Expartanos
Aplicativo de organização e foco nos estudos, combinando Pomodoro, lista de tarefas e gamificação para ajudar estudantes a criar uma rotina de estudos mais consistente.

### Funcionalidades
- Pomodoro: sessões de foco com pausa automática caso o usuário saia do app.
- To-do List: criação e acompanhamento de tarefas de estudo.
- Metas: definição e acompanhamento de objetivos de estudo.
- XP e níveis: o usuário ganha pontos ao estudar e concluir tarefas.
- Ranking: competição entre usuários baseada no desempenho.
- Flash Card: para revisar o conteúdo.
- Streak: acompanhamento da sequência de dias estudados.
- Estatísticas: histórico e evolução dos estudos.
